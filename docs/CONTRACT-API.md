# UI және контракт API

ABI: frontend/src/contracts/TicketChain.abi.json, generated by npm run compile. All writes require a successful receipt before UI success.

| UI action | Function | Arguments | Value | Result |
|---|---|---|---|---|
| Catalog | getEvents | offset, limit 1..100 | none | EventData[] |
| Event detail | getEvent | eventId | none | EventData |
| Seat map | getSeatTicketIds | eventId | none | uint256[], zero = available |
| Buy | buyTicket | eventId, seatNumber | exact ticketPrice wei | TicketPurchased includes ticketId |
| Wallet tickets | getUserTicketIds | owner, offset, limit | none | ticket IDs |
| Wallet count | getUserTicketCount | owner | none | count |
| Ticket/QR | getTicket | ticketId | none | Ticket |
| Create | createEvent | title, metadataURI, startsAt, endsAt, ticketPrice, capacity | 0 | EventCreated |
| Pause | setEventSalesPaused | eventId, bool | 0 | SalesPausedChanged |
| Checker | setChecker | eventId, checker address, bool | 0 | CheckerUpdated |
| Authorization | admin / isChecker | none / eventId,address | none | address / bool |
| Entry | checkIn | ticketId | 0 | TicketCheckedIn |
| Cancel | cancelEvent | eventId | 0 | EventCancelled |
| Refund | refundTicket | ticketId | 0 | TicketRefunded |
| Withdraw | withdrawProceeds | eventId | 0 | ProceedsWithdrawn |

EventData: id, organizer, title, metadataURI, startsAt, endsAt, ticketPrice, capacity, ticketsSold, checkedInCount, refundedCount, salesPaused, cancelled, escrowBalance, proceedsWithdrawn.

Ticket: id, eventId, seatNumber, owner, pricePaid, used, refunded.

All numeric contract values are bigint in ethers v6. Times are seconds. UI inputs/display use UTC+5. `getEvent` collides with ethers Contract's own method; the service always calls `contract.getFunction(name)(...args)`.

On-chain IDs start at 1; pagination offset starts at 0. Cancel is allowed strictly before startsAt minus 3600 seconds; entry is allowed inclusively from that boundary through endsAt. Withdrawal is allowed at/after endsAt for a noncancelled event. Buyers cannot transfer tickets. Refund follows checks-effects-interactions; adversarial receiver tests prove same-ticket reentry does not pay twice and failed transfers roll back.
