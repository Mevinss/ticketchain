# GitHub-қа не жазу керек

## About → Description

GitHub репозиторийінің оң жағындағы **About → Edit** өрісіне дайын мәтін:

```text
Educational Ethereum ticketing smart contract: seat booking, check-in, event cancellation, refunds, and per-event ETH escrow. Built with Solidity 0.8.24 for Remix IDE.
```

Қазақша нұсқасы:

```text
Ethereum блокчейнінде билет сату: орын таңдау, билетті тексеру, іс-шараны тоқтату және төлемді қайтару. Solidity 0.8.24 және Remix IDE негізіндегі оқу жобасы.
```

**Website:** жұмыс істейтін демо жарияланған жағдайда ғана оның сілтемесін қосыңыз. Қазіргі репозиторийде жарияланған веб-интерфейс көрсетілмеген.

## Release tag пен Topics айырмасы

**Topics** жобаның тақырыбы мен технологияларын көрсетеді. **Release tag**, мысалы `v0.1.0`, кодтың нақты нұсқасын белгілейді. Алғашқы оқу прототипіне релиз шығаруды шешсеңіз:

```text
Tag: v0.1.0
Title: TicketChain — Educational Smart Contract Prototype
```

Релиз сипаттамасына билет сатып алу, check-in, refund және escrow мүмкіндіктерін жазыңыз. Remix VM үшін екенін және тесттердегі белгілі мәселелерді көрсетіңіз. Бұл нұсқа тегі әзірше ұсыныс; осы құжат оны жасамайды.

## Жобаны таныстыруға арналған қысқа сипаттама

TicketChain — Ethereum блокчейні негізінде іс-шара билеттерін сатудың оқу прототипі. Смарт-контракт әр орынды бір рет сатуды, билет иесін тіркеуді және check-in кезінде қайталанған пайдалануды шектеуді қамтамасыз етеді. Билет төлемдері контракт балансында сақталып, әр іс-шара бойынша бөлек есептеледі: іс-шара тоқтатылса, билет иесі төлемін қайтара алады; іс-шара аяқталса, ұйымдастырушы түсімді шығарады. Жоба Solidity 0.8.24 тілінде жасалған және Remix VM арқылы көрсетіледі.
