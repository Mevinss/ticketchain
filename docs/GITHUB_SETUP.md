## Чем Release tag отличается от Topics

**Topics** описывают тематику и технологии проекта. **Release tag**, например `v0.1.0`, отмечает конкретную версию кода. Если решите выпустить первый учебный прототип, можно использовать:

```text
Tag: v0.1.0
Title: TicketChain — учебный прототип смарт-контракта
```

В описании релиза перечислите покупку билетов, check-in, возвраты и хранение оплаты до завершения мероприятия. Укажите, что проект предназначен для Remix VM, и перечислите известные проблемы тестов. Тег версии здесь только предложен; этот документ не создаёт релиз.

## Краткое описание для представления проекта

TicketChain — учебный прототип продажи билетов на мероприятия на базе блокчейна Ethereum. Смарт-контракт обеспечивает однократную продажу каждого места, регистрацию владельца билета и запрет повторного использования при check-in. Оплата хранится на балансе контракта и учитывается отдельно по мероприятиям: при отмене владелец билета может вернуть средства, а после завершения организатор может вывести выручку. Проект написан на Solidity 0.8.24 и демонстрируется через Remix VM.
